# RoosterWorks Rescue v1.0.0

This unified release combines two existing Contract Configurator rescue and exploration packs for KSP 1.12.5.

**Included campaigns:** Agency Station & Surface Rescue **v2.27** (8 contracts and 8 craft files) and Interstellar Expansion Campaign **v1.3** (11 contracts and 4 craft files). Contracts cover Kerbin-system rescues, damaged stations/bases, salvage missions, and progression involving Promised Worlds, Plock and Bop.

**Installation:** Extract the named `RoosterWorks-Rescue-v1.0.0.zip` release asset into the KSP installation root, preserving both `GameData/AgencyStationRescue/` and `GameData/InterstellarExpansionCampaign/`. Remove old versions first; do not rename those two folders.

**Dependencies:** Contract Configurator, Kerbalism, SSPXr, KPBS/ModuleManager and the planet packs/content mods described in the repository README. Other third-party part mods may be necessary for individual supplied craft.

This repackaging changes public project naming and documentation, **not** gameplay contracts/craft. Internal mission IDs and paths are deliberately retained. Offline validation covers mission counts, craft references and SHA-256 file integrity; game runtime behavior still depends on installed mods.
